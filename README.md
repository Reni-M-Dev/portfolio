# Reni Mangukiya – Video Editor Portfolio
Static site: HTML, CSS, Bootstrap 5 (CDN), vanilla JS. No build step.

## Preview
Open `index.html`, or run `python3 -m http.server` and visit localhost:8000.

## Replace content (search `REPLACE` in index.html)
- Hero image: `assets/images/hero.jpg`; profile: `assets/images/profile-placeholder.jpg`
- Projects: edit `.card-work` buttons (`data-video`, `data-poster`, title, category). Files: `assets/videos/project-0X.mp4`, `assets/images/project-0X.jpg`
- About, Experience, Tools, Contact links, and the email in `js/script.js`
- Project 03 and 04 are placeholders (no video yet)

## Deploy free
GitHub Pages / Netlify / Vercel: upload folder, publish root. Keep videos small (compress; GitHub limit 100 MB/file).
